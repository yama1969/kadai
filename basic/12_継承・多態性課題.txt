■■ 課題1010 --- あらゆるオブジェクトを扱えるスタック ------------------------

以前の課題で作成したIntStackExはint型のデータしか格納できない。
これをあらゆる型のオブジェクト(インスタンス)を格納できるように変更し、
ObjectStackというクラス名で作成する。

データを持つオブジェクトのクラスも変更すること。
クラス名はObjectDatとする。ソース内容は、intをObjectに置換すればよい。

変更内容
クラス名 :
  (旧)IntStackEx
  (新)ObjectStack

フィールド :
  (1)データオブジェクトの型をIntDatからObjectDatにする。

メソッド :
  (1)(旧)public int push(int dat)
     (新)public int push(Object dat)
  
  (2)(旧)public int pop()
     (新)public Object pop() にする。
           データが無い場合は、nullを返すように変更。
  
  (3)(旧)public int get()
     (新)public Object get()
           データが無い場合は、nullを返すように変更。


上記のクラスの動作を確認するため、次のような動作をするプログラムを
main()メソッドで作成する。(main()メソッドはKadai1010クラス。)
内容は以前と変わらない。必要な部分のみ変更すること。

なお、int型データはそのままではオブジェクトとして扱えないので、
ラッパークラスを用いてオブジェクトにする。
  (例) 5というint型データをオブジェクトにする
       Integer num = new Integer(5);

Integerオブジェクトからint型データを取り出すには、intValue()を使う。
       Integer num = new Integer(5);
       int n = num.intValue();       //nには5が代入される

また、ObjectDatオブジェクトのget()やpop()を使うと、その戻り値は
実態はIntegerオブジェクトであっても、Object型で得られる。
したがって、キャストが必要となる。
       ObjectStack stack = new ObjectStack();
       stack.push(new Integer(5));
       Integer num = (Integer)stack.get();


1. コマンドを文字で入力し、それにより以下の処理をする。
     (1)e ・・・ プログラムの終了(end)
     (2)i ・・・ データをスタックにpushする(in)
                   データを整数で入力し、スタックに積む。
                   積んだ後のスタック内のデータ数を表示する。
                   スタックが満杯の場合は、「すでに満杯です。」と表示する。
     (3)o ・・・ データをスタックからpopする(out)
                   popしたデータを表示する。
                   popした後のスタック内のデータ数を表示する。
                   スタックが空の場合は、「すでに空です。」と表示する。
     (4)g ・・・ スタックの最上のデータの表示(get)
                   スタックの最上のデータを得、表示する。
                   スタックが空の場合は、「すでに空です。」と表示する。
     (5)c ・・・ 積んであるデータ数の表示(count)
     (6)a ・・・ スタックの消去(all)
                   スタックのデータを全て削除する。
     その他の場合は何も動作しない。
2. 1.にもどる


※継承の親の型の参照変数には、子の型のインスタンスを代入することができる。
  Javaでは全てのクラスがObjectクラスを継承しているので、Object型の参照変数には
  あらゆる型のインスタンスを代入できる。

※Javaの場合、intやdoubleなどの基本データ型には対応するラッパークラスがある。
  例えばint型に対するIntegerクラス、double型に対するDoubleクラスがそれである。
  この仕組みにより、事実上、Object型の参照変数には基本データ型も含めた
  ありとあらゆるデータを代入できることになる。

■■ 課題1130 --- ジェネリクス ～ 型指定できるリスト --------------------------

前の課題で作成したObjectListは、いかなる型のインスタンスも扱えるので
便利ではあるが、いちいち型チェックと型キャストをしなければならないので、
その点は煩わしい。

これを改善するため、ObjectListをジェネリクスを用いたものに改善する。
改善後のクラス名は「ObjectListG」とする。

ObjectListGのクラス宣言を次のように行う。
  public class ObjectListG<E>
このようにすると、ObjectListGを利用する側のプログラムで
  ObjectListG<String> list = new ObjectListG<String>();
と記述し、String型のリストとして利用することができる。
つまり、<E>の部分は、利用側で任意の参照型を指定できる。

ObjectListGクラス内で、<E>で指定された型を使う箇所の型表記はEとする。
例えば、get(int index)メソッドは戻り値の型が<E>で指定された型になるので、
  public E get(int index)
のように宣言する。

このように、実行時に任意の型を指定する方法をジェネリクスという。

ただし、配列にはジェネリクス型は使えない。例えばtoArray()メソッドは、
  public E[] toArray()
とできない。
  public Object[] toArray()
とし、利用側プログラムで個々の要素をキャストしながら使う。
(E[]と型指定するとコンパイルは通るが、実行時、E[]型変数に代入する所で
 キャスト例外が発生する。
 また、new E[] と記述すると、これはコンパイルエラーになる。)

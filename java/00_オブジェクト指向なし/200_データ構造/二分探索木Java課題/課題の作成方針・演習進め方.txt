「二分探索木フローチャート課題」で作成した処理をJavaプログラムに起こす課題

●「二分探索木フローチャート課題」は次のフォルダにある。
\00.Data\21.セミナー使用データ集\基本情報・シスアド\040_問題や演習\自作\二分探索木フローチャート課題

●課題作成の方針

　(1)フローチャート課題は探索・挿入・表示・削除の各処理に分かれているので、その処理ごとにメソッドを作成。

　(2)実行しやすいように、クラスは1つとする。

●演習の進め方
　(1)フローチャートの課題の順に、メソッドを作成。
　(2)メソッドを作成するたびにmainメソッドを作成あるいは変更し、実行してみる。
　(3)正常系だけでなく、値が見つからない場合などの異常系の動作も確認するようにmainメソッドを作成。

　※スキルが既にやや高めの場合は、受講生同士でフローチャートを交換し、プログラミングしても良い。

■■ Keyboardクラスの概要

Keyboardクラスは、コンソールアプリにおける
キーボード入力を簡単に実行するためのクラスです。

例えばint型の数値のキーボード入力を
以下のようなコードで実行できます。

int a = Keyboard.readInt();

このコードを実行すると、コンソールに
「 => 」というプロンプトが表示され、
それに従ってユーザが整数を入力すると、
その整数が変数aに代入されます。


■■ Keyboardクラス使用時の注意

Keyboardクラスを使用するには、
あなたが作成するJavaプログラムと同じディレクトリに
ファイルKeyboard.classを配置しなくてはなりません。

(もう少し正確に説明すると、Keyboard.classにclasspathが
 通っていなくてはなりません。)


■■ Keyboardクラスの各メソッド

Keyboardクラスの各メソッドは全てクラスメソッドなので、
newキーワードでKeyboardインスタンスを生成する必要はありません。

Keyboardクラスには、次の3個のメソッドがあります。
入力するデータの型に応じて使い分けます。

  1. int型整数入力 ・・・ Keyboard.readInt()
       整数を入力します。
       int型整数以外の入力があった場合や異常があった場合は、
       int型の最小値(-2147483648)を返します。

  2. char型文字入力 ・・・ Keyboard.readChar()
       1文字を入力します。
       複数文字が入力された場合は、先頭の1文字を返します。
       異常があった場合は文字コード0を返します。

  3. String型文字列入力 ・・・ Keyboard.readString()
       文字列を入力します。
       異常があった場合は、nullを返します。

どのメソッドも、引数にプロンプトメッセージを入れることができます。
例えば、

int a = Keyboard.readInt("個数を入力");

というコードを実行すると、コンソールには
「個数を入力 => 」というプロンプトが表示されます。


■■ 使用例

  1. 整数入力
     public class TestInt{
         public static void main(String[] args){
             int a = Keyboard.readInt("整数を入力");
             System.out.println("入力された整数は、" + a + " です");
         }
     }

  2. 文字入力
     public class TestChar{
         public static void main(String[] args){
             char c = Keyboard.readChar("1文字を入力");
             System.out.println("入力された文字は、" + c + " です");
         }
     }

  3. 文字列入力
     public class TestString{
         public static void main(String[] args){
             String str = Keyboard.readString("文字列を入力");
             System.out.println("入力された文字列は、" + str + " です");
         }
     }

以上です。

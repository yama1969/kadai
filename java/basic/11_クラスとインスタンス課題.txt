■■ 課題1110 --- サイズが自動的に変化するスタック ----------------------------

以前の課題で作成したInsStackを改善し、サイズが自動的に変化するようにする。
これにより、newするときにサイズを指定する必要はなく、メモリが許す限りスタックに
積むことができるようになる。

考え方
  ・スタックに積むひとつひとつのデータをオブジェクトとする。
  ・それぞれのオブジェクトは、データの他に、自分の前のオブジェクトへの
    参照を持つ。
  ・最上に積まれているオブジェクトへの参照変数を用意する。

  +------------------+    +-----------------------------+
  | 最上への参照変数 | → | 上から1つめの値オブジェクト |
  +------------------+    +-----------------------------+
                                        ↓
                          +-----------------------------+
                          | 上から2つめの値オブジェクト |
                          +-----------------------------+
                                        ↓
                          +-----------------------------+
                          | 上から3つめの値オブジェクト |
                          +-----------------------------+

処理方法
  (1)スタックに積むとき(push)
       1. 新たに積むデータのオブジェクトを生成し、最上への参照変数が
          参照しているオブジェクトを、新たに積むデータのオブジェクトの
          参照先とする。
       2. 最上への参照変数の参照先を、新たに積むデータのオブジェクトとする。
  
  (2)スタックから取り出すとき(pop)
       1. 最上への参照変数の参照先を、最上のデータオブジェクトの参照先にする。
       2. 元々最上だったデータオブジェクトをreturnする。

改善したクラスの名前はIntStackExとする。
また、データオブジェクトのクラス名はIntDatとする。

データオブジェクトは以下のように作成すると良いだろう。
フィールド :
  (1)private int data
       データオブジェクトが持つデータ。
  (2)private IntDat neighbor
       このデータオブジェクトの、前のデータオブジェクトへの参照。

コンストラクタ :
  (1)public IntDat(int data, InsDat neighbor)
       データと前のオブジェクトをセットするコンストラクタ。

メソッド :
  (1)public int getData()
       このオブジェクトが持つデータを得る。
  (2)public IntDat getNeighbor()
       このオブジェクトの前のオブジェクトを得る。
  (3)public void setNeighbor(IntDat neighbor)
       このオブジェクトの前のオブジェクトをセットする。

※setNeighbor()メソッドは今回は使わないが、将来のために作成しておく。

       戻値 : 生成された新しい会員を表すMemberExインスタンス
  (2)public static int getCount()
       現在の会員数を得る。
       引数 : なし
       戻値 : 現在の会員数

[新会員生成処理newMember()の内容]
1. 新会員の氏名を入力する。
2. 新会員の電話番号を入力する。
4. MemberExインスタンスをnewする。
   コンストラクタ内でcountを+1する。そして会員番号はcountと同じ値とする。
5. 4.でnewしたMemberExインスタンスに、氏名と電話番号をセットする。
6. 4.でnewしたMemberExインスタンスをreturnする。


※これらのフィールドやメソッドは、インスタンスによって変わるものではなく、
  MemberExインスタンス共通のものである。
  個数であるcountなどはインスタンスによって違う値になったりしない。
  また、newMember()やgetCount()はインスタンスによって処理結果が
  変わったりしない。
  このようなフィールドやメソッドはstaticにする。
  
  それに対し、nameやtel、titleはインスタンスごとに違う値を持つ。
  また、rent()やback()などのその他のメソッドは、nameやtel、titleなどの
  インスタンスによって違う値を処理するので、処理結果は
  インスタンスによって変わる。
  このようなフィールドやメソッドはstaticにしない。

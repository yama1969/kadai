■■ 課題2400 --- 浮動小数点型のワナ ～ 丸め誤差の実験 ------------------------

1. 1つめのdouble型の変数に0.57を代入する。
2. 2つめのdouble型の変数に0.52を代入する。
3. 2つのdouble型変数の値を表示する。
4. 1つめの変数と2つめの変数との差が0.05以上ならば「差は0.05以上」と表示する。

※0.57 - 0.52 の差は 0.05 だから、数学的には「差は0.05以上」となるはずだが・・

※浮動小数点型であるdouble型とfloat型は、本質的に誤差を含んでいる。(丸め誤差)
  浮動小数点型を使うときには、誤差を含んでいることを念頭に置く必要がある。
  したがって、浮動小数点型に対しては「等しい」という比較はしない。
  次の3つは、等しいという意味を含むので、浮動小数点型への使用は避ける。
  
    等しい ==
    以上   >=
    以下   <=

※小数型の誤差については、Excel等でも同様である。
  試しに上記の判定をExcelのIF関数でやってみると、同じ誤りを起こす。



■■ 課題2425 --- 浮動小数点型のワナ ～ 端数処理 ------------------------------

上の課題のプログラムに、端数処理を入れる。

1. double型変数 a に0.57を代入する。
2. double型変数 b に0.52を代入する。
3. 2つのdouble型変数の値を表示する。
4. long型変数 l_a に (a * 100.0) を四捨五入して整数に丸めた値を代入する。
5. long型変数 l_b に (b * 100.0) を四捨五入して整数に丸めた値を代入する。
6. l_a と l_b との差が5以上ならば「差は0.05以上」と表示する。
     そうでなければ「差は0.05未満」と表示する。

※四捨五入した値は次のようにして求められる。
    long l_a = Math.round(a * 100.0);

※Math.round()は小数点第1位を四捨五入して整数にするメソッド(命令)である。
  小数点第3位を四捨五入するには、値をあらかじめ100倍しておけば良い。
  0.569 →(100倍)→ 56.9 →(round)→ 57

※四捨五入する桁の位置は、そのデータが小数点第何位まで有効な値なのかによる。
  例えば、気温データならば「16.8℃」「23.2℃」「15.0℃」なので、
  小数点第1位までが有効な値である。従って、四捨五入は小数点第2位で行う。
  今回の課題では小数点第2位までが有効な値なので、小数点第3位で四捨五入した。

※浮動小数点型は誤差を含むが、整数型は誤差を含まないので、
  小数データを扱うときは上記のように整数型に変換して処理するのが基本。
  
  浮動小数点型の誤差に気をつけなければならないのは、次のような処理を
  するときである。
    (1)小数を含む値に対して、等しいか否かを判定するとき。
         つまり、== , <= , >= を用いるとき。
    (2)小数を含む値に対して、計算を繰り返すとき。
         繰り返し毎に誤差が蓄積され、最終的に大きな誤差となる。
         例えば、金融の複利計算などがこれに当たる。
  このような処理をするときには、小数を整数型に変換する。

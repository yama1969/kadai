■■ 課題1800 --- switch文のネスト ～ ガチンコでじゃんけん --------------------

switch文のみで記述すること。
1. じゃんけんの手を整数で入力する。
     0ならグー、1ならチョキ、それ以外ならパーとする。
2. 0～2の整数乱数を生成し、これをコンピュータの手とする。
3. 入力された手とコンピュータの手を表示する。
4. 勝敗を判定し、その結果によって
     「あいこですね」「私の勝ちですね」「私の負けですね」を表示する。

※if文の課題でも同じものがあった。どちらが読みやすいだろうか。

※勝敗は、以下の式でも判定できる。
  プレイヤーの手を   p_hand
  コンピュータの手を c_hand とすると、

  int result = (c_hand + 3 - p_hand) % 3;

  resultが 0ならあいこ、1ならコンピュータの負け、2ならコンピュータの勝ち
  
  ただし、この判定方法が後からプログラムを見たときに分かりやすいかと言うと、
  技巧的すぎて分かり難い。

  プレイヤーとコンピュータの手の組み合わせが9通りもあるので、
  switch文で判定すると結構な記述量になる。
  しかし、後々の理解しやすさを優先して少々記述が増える書き方をすることも、
  業務プログラミングでは良くあることである。
  (msやns単位の処理時間短縮が求められる時は、理解しやすさより速度を優先する。)

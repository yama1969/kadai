コンソール画面でのキーボード入力を便利にするためのクラスを作成する。

■■ クラス名 -----------------------------------------------------------------

public Keyboard


■■ フィールド ---------------------------------------------------------------

なし


■■ コンストラクタ -----------------------------------------------------------

private Keyboard()
     コンストラクタはprivateとし、newできないクラスにする。処理は特にない。
     (staticメンバだけの利用)


■■ メソッド -----------------------------------------------------------------

1. public static String readString()
     文字列を入力する

     使用イメージ
       呼出しコード : Keyboard.readString();
       画面表示     : あいうえお
                      (「あいうえお」は入力した文字列)

2. public static String readString(String mess)
     メッセージとプロンプトを表示し、文字列を入力する

     使用イメージ
       呼出しコード : Keyboard.readString("挨拶を入力 => ");
       画面表示     : 挨拶を入力 => あいうえお
                      (「あいうえお」は入力した文字列)

3. public static int readInt()
     プロンプトを表示し、int型整数を入力する

     使用イメージ
       呼出しコード : Keyboard.readInt();
       画面表示     : 48
                      (「48」は入力した整数)

4. public static int readInt(String mess)
     メッセージとプロンプトを表示し、int型整数を入力する

     使用イメージ
       呼出しコード : Keyboard.readInt("値を入力 => ");
       画面表示     : 値を入力 => 48
                      (「48」は入力した整数)


■■ その他 -------------------------------------------------------------------

入力に使用するAPIクラスであるBufferedReaderは、次のようにtry～catchブロック内で
使用すると、メソッドの後ろのthrows・・・の記述が不要となり、そのメソッドを呼び
出す側のメソッドの後ろもthrows・・・の記述が不要となる。
(try～catchについてはLesson14で学ぶ)

public static String inputString(){
	String str = null;
	try{
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		str = br.readLine();
		//つづきのコード
		
	}catch(Exception e){
	}
	return str;
}

■■ 動作確認 -----------------------------------------------------------------

Keyboardクラスが出来上がったら、Keyboardクラスの各メソッドを呼び出す下記の
ようなmain()メソッドを持つクラスを作成し、実行して動作確認を行うこと。

このような、作成したプログラムを駆動する動作確認のためのモジュール(クラス)を
「ドライバ」という。(基本情報p463)

public static void main(String[] args){
	System.out.println("Keyboardクラスの動作テストを行います。");
	System.out.println("最初は文字列の入力テストです。");
	System.out.println();
	
	String str = Keyboard.readString();
	System.out.println("文字列「" + str + "」が入力されました。");
	System.out.println();
	
	str = Keyboard.readString("文字列を入力してください : ");
	System.out.println("文字列「" + str + "」が入力されました。");
	System.out.println();
	
	System.out.println("続いて整数の入力テストです。");
	System.out.println();
	int i = Keyboard.readInt();
	System.out.println("整数" + i + "が入力されました。");
	System.out.println();
	
	int i = Keyboard.readInt("整数を入力してください : ");
	System.out.println("整数" + i + "が入力されました。");
	System.out.println();
}

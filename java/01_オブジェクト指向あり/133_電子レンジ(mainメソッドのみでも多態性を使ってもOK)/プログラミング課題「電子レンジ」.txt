■プログラミング演習内容

  電子レンジの制御プログラムを作成します。

  ●動作内容

  ・メインフロー
    1.ユーザがシステムにメニュー番号を入力する [Alt.A]
    2.システムは、入力されたメニュー番号に対応する動作を行い、終了する

  ・代替フロー[Alt.A](ユーザが不正なメニュー番号を入力した場合)
    1.システムは、入力されたメニュー番号が不正の旨をユーザに知らせる
    2.メインフローの1.に戻る

  ●メニュー一覧

  ・メニュー番号11 「とにかく温め」
    1.出力「強」で10秒間動作する
    2.動作を終了する

  ・メニュー番号12 「じっくり温め」
    1.出力「強」で2秒間動作する
    2.出力「弱」で1秒間動作する
    3.上記の1.～2.を3回繰り返す
    4.動作を終了する

  ・メニュー番号21 「焦げ目もきれいに」
    1.出力「強」で5秒間動作する
    2.「オーブン」で3秒間動作する
    3.上記の1.～2.を、動作時間を1秒ずつ減らしながら3回繰り返す
    4.動作を終了する

  ●動作表示方法

    動作状況を、画面にメッセージとして表示します。

    [例 : メニュー番号12の場合]
      出力「強」
          :
          :   (←実際に2秒待つ。以下同様)
          :
          :

          :   (←1秒待つ)
          :
      出力「強」
          :
          :   (←2秒待つ)
          :
          :
      出力「弱」
          :   (←1秒待つ)
          :
      出力「強」
          :
          :   (←2秒待つ)
          :
          :
      出力「弱」
          :   (←1秒待つ)
          :
      完了
